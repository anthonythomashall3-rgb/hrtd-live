Downloads

Every series page has a Download CSV button. The file holds every first print of the series with four columns:

ColumnMeaning
series_idThe HRTD series ID
periodThe period the value describes (first day of the month, quarter or year; or the day or week-ending day)
valueThe first-print value, exactly as published
release_dateThe day the value became public; empty when not yet found

To find a series, use the search box or browse by function, source or release.
